本条目按本次讨论整理常见名词，使用简明解释帮助阅读星表、器材参数和深空摄影流程。具体坐标、测光及校准操作还需结合参考系统、波段、相机与软件说明。未加入本人的器材配置或实拍经历。

## 优先理解的12个词

**视星等、面亮度、角秒、赤经、赤纬、视场、焦比、视宁度、信噪比、导星、叠加、拉伸。**

它们分别帮助判断目标亮度与大小、寻找目标、安排构图，以及理解照片质量与处理过程。

## 1. 距离与角度

| 名词 | 英文或缩写 | 含义 |
| --- | --- | --- |
| 天文单位 | au / AU | 常用于太阳系距离，1 au精确定义为149,597,870,700 m，约1.496亿千米 |
| 光年 | Light-year，ly | 光在真空中一个儒略年内走过的距离，约9.46万亿千米，是距离单位 |
| 秒差距 | Parsec，pc | 与恒星视差测距有关的距离单位，1 pc约3.26光年 |
| 千秒差距 | kpc | 1000 pc，常用于银河系尺度 |
| 百万秒差距 | Mpc | 100万pc，常用于星系及更大尺度 |
| 角分 | Arcminute，′ | 角度单位，1°＝60′ |
| 角秒 | Arcsecond，″ | 角度单位，1′＝60″，1°＝3600″ |
| 视大小、角直径 | Angular size / diameter | 天体在天空中占据的角度，与真实大小和距离都有关系 |

“星云宽1°”描述天空中的大小；“距离1000光年”描述远近。角秒不是时间秒，光年也不是时间单位。[S1、S2]

## 2. 亮度与颜色

| 名词 | 英文或符号 | 含义 |
| --- | --- | --- |
| 视星等 | Apparent magnitude，m | 从观测者位置看到的亮度尺度，数值越小越亮，可以是负数 |
| 绝对星等 | Absolute magnitude，M | 按规定波段和约定，将天体放到10 pc处时对应的星等，用于比较本身的发光能力 |
| 光度 | Luminosity，L | 单位时间发出的能量，可指总光度或特定波段光度 |
| 面亮度 | Surface brightness | 单位角面积上的亮度，常用mag/arcsec²表示，对扩展目标尤其重要 |
| 色指数 | 如B−V | 两个波段星等之差，描述颜色，可辅助研究温度、消光等 |
| 有效温度 | Effective temperature | 用总辐射通量定义的温度指标，常用于描述恒星辐射特性 |
| 消光 | Extinction | 光经过尘埃、大气等后减弱的现象 |
| 红化 | Reddening | 不同波长受到不同程度的衰减，使天体颜色偏红的现象 |

同一波段下，星等差5等，接收亮度相差100倍。比较绝对星等或色指数时也要核对波段。总星等相同的目标，如果光分散在更大角面积上，通常更难拍出。[S3；摄影比较为原理归纳]

## 3. 天空坐标与运动

| 名词 | 英文或缩写 | 含义 |
| --- | --- | --- |
| 天球 | Celestial sphere | 为描述天空方向而设想的球面 |
| 赤经 | Right Ascension，RA / α | 类似天空经度的角坐标，常用时、分、秒表示，24h对应一周 |
| 赤纬 | Declination，Dec / δ | 相对天赤道向北或向南的角坐标，范围为−90°至＋90° |
| 高度角 | Altitude，Alt | 相对地平面的角度，地平线为0°，天顶为90° |
| 方位角 | Azimuth，Az | 沿地平方向的位置角，使用软件时需核对零点和方向约定 |
| 天顶 | Zenith | 观测者正上方的天空方向 |
| 上中天 | Upper culmination | 天体经过当地子午圈、靠近天顶一侧的位置 |
| 时角 | Hour angle，HA | 表示天体相对当地子午圈的位置，与当地恒星时及赤经有关 |
| 恒星时 | Sidereal time | 以天空参考方向定义的时间，用于天体定位等 |
| 自行 | Proper motion | 恒星空间运动在天球上表现出的角位置变化，常用角秒/年表示 |
| J2000.0 | 标准历元标记 | 星表和坐标中常见的参考时刻标记；实际使用还要核对参考系统及历元含义 |

赤经中的“时、分、秒”在这里表示角位置，不能直接当成当天钟表时间。高度角、方位角还依赖地点和观测时刻。[S2]

## 4. 目标名称、目录与缩写

| 名词 | 全称或含义 | 例子或说明 |
| --- | --- | --- |
| 深空天体 | Deep-Sky Object，DSO | 摄影中通常指太阳系外的星云、星团、星系等 |
| 梅西耶目录 | Messier，M | 如M31仙女座星系、M42猎户座星云 |
| 新总星表 | New General Catalogue，NGC | 如NGC 7000北美星云 |
| 索引星表 | Index Catalogue，IC | 如IC 1805心脏星云 |
| 巴纳德暗星云目录 | Barnard，B | 如B33马头星云 |
| 沙普利斯目录 | Sharpless，Sh2 | 主要收录电离氢区 |
| 电离氢区 | HⅡ region | 富含电离氢，通常与年轻大质量恒星有关的区域 |
| 行星状星云 | Planetary Nebula，PN | 中低质量恒星晚期抛出的外层物质形成的星云，与行星没有直接关系 |
| 超新星遗迹 | Supernova Remnant，SNR | 超新星爆炸后的抛射物及受影响区域 |
| 星际介质 | Interstellar Medium，ISM | 恒星之间的气体、尘埃等物质 |
| 活动星系核 | Active Galactic Nucleus，AGN | 星系中心活跃区域，通常由超大质量黑洞吸积供能 |

目录编号不是天体类型，同一目标可以有多个编号，例如M31也称NGC 224。天体类别的图例与物理说明见[深空摄影条目](deep-sky-astrophotography.md)。[S3及关联条目来源]

## 5. 光谱、波段与滤镜

| 名词 | 英文或缩写 | 含义 |
| --- | --- | --- |
| 光谱 | Spectrum | 光强随波长或频率变化的分布 |
| 连续谱 | Continuum | 在一段波长范围内连续分布的辐射 |
| 发射线 | Emission line | 光谱中特定波长附近增强的明亮特征 |
| 吸收线 | Absorption line | 光谱中特定波长附近相对变暗的特征 |
| 红移 | Redshift，z | 光谱特征移向较长波长；可与相对运动、宇宙膨胀或引力有关 |
| 宽带 | Broadband | 通过或记录较宽波长范围的方式 |
| 窄带 | Narrowband | 通过较窄波长范围，常用于记录指定发射线 |
| Hα | Hydrogen-alpha | 氢的一条重要谱线，静止波长约656.3 nm，位于红光区 |
| OⅢ | Doubly ionized oxygen | 失去两个电子的氧；摄影常用其约500.7 nm发射线 |
| SⅡ | Singly ionized sulfur | 失去一个电子的硫；摄影常用其红光区发射线 |
| LRGB | Luminance＋RGB | 亮度数据与红、绿、蓝颜色数据的组合 |
| SHO、HOO | 窄带组合和配色简称 | 指所用发射线及显示映射，不直接等于肉眼颜色 |

光谱概念见S3，红移见S4；滤镜与配色实例见[深空摄影条目第4节](deep-sky-astrophotography.md#4-宽带窄带与颜色)。

元素后的罗马数字中，Ⅰ表示中性原子，Ⅱ表示失去一个电子，Ⅲ表示失去两个电子。HⅡ中的“Ⅱ”与Hα中的“α”不是同一类标记。

## 6. 望远镜与天空条件

| 名词 | 英文或缩写 | 含义 |
| --- | --- | --- |
| 口径 | Aperture，D | 主要入光口的有效直径，影响集光及理论分辨能力 |
| 焦距 | Focal length，f | 与传感器尺寸共同决定视场和目标在照片中的大小 |
| 焦比 | Focal ratio，f/D | 焦距除以口径，例如400 mm÷80 mm＝f/5 |
| 视场 | Field of View，FOV | 一张照片覆盖的天空范围 |
| 像元尺度 | Image scale | 每个像素对应的天空角度，常用″/pixel |
| 分辨率 | Resolution | 区分相邻细节的能力，不能只凭像素总数判断 |
| 视宁度 | Seeing | 大气湍流造成星像抖动、展宽的程度 |
| 透明度 | Transparency | 大气透光情况，受云、雾、气溶胶等影响 |
| 半高全宽 | Full Width at Half Maximum，FWHM | 星像亮度轮廓在峰值一半高度处的全宽，常用于描述星点大小 |

透明度好有利于接收微弱光，视宁度好有利于记录精细结构。图像中的FWHM还受对焦、跟踪、光学和采样影响，不能直接当作纯粹的大气视宁度。[S5]

视场与像元尺度的计算和构图示例见[深空摄影条目](deep-sky-astrophotography.md)。

## 7. 拍摄、跟踪与相机参数

| 名词 | 英文或缩写 | 含义 |
| --- | --- | --- |
| 赤道仪 | Equatorial mount，EQ | 通过赤经轴跟踪等方式补偿地球自转的架台 |
| 极轴校准 | Polar alignment | 让赤道仪极轴对准相应天极方向 |
| 导星 | Autoguiding | 根据参考星的偏移持续修正跟踪 |
| 导星RMS | RMS guiding error | 导星误差的均方根统计量，比较时需核对单位、采样和统计条件 |
| 抖动 | Dithering | 曝光之间有意小幅改变指向，帮助后续抑制固定图样和坏点影响 |
| 单张曝光 | Sub-exposure / Sub | 一张亮场的曝光时间 |
| 总积分时间 | Total integration | 最终采用的有效亮场曝光时间之和 |
| 增益 | Gain | 与电子信号转换为数字值的比例有关，不会增加实际收到的光子 |
| 偏置量 | Offset | 相机读出时加入的基线，帮助避免低端数据截断 |
| 信噪比 | Signal-to-Noise Ratio，SNR | 有用信号相对于噪声波动的强弱 |

导星与抖动参照S6；相机电子学及校准概念参照S7。不同设备的Gain刻度不同，不能仅凭菜单数值比较。

SNR在目标分类中也表示“超新星遗迹”，应根据上下文判断；Offset相机参数与Bias校准帧也不是同一个操作。

## 8. 校准与后期

| 名词 | 英文 | 含义 |
| --- | --- | --- |
| 亮场 | Light | 正常拍摄天体的原始图像 |
| 暗场 | Dark | 遮光曝光，用于估计暗电流及相关固定图样 |
| 平场 | Flat | 拍摄均匀照明，用于校准暗角、灰尘影和响应差异 |
| 偏置帧 | Bias | 遮光、极短曝光，用于估计电子学基线及固定读出结构 |
| 暗平场 | Dark flat / Flat dark | 与平场曝光等条件匹配的遮光帧，用于校准平场 |
| 配准 | Registration | 将多张图像中的相同目标对齐 |
| 叠加 | Stacking / Integration | 合并多张图像，改善信噪比并抑制异常值 |
| 拉伸 | Stretch | 调整亮度映射，使暗弱结构在显示中显现 |
| 背景提取 | Background extraction | 建模并校正背景渐变，同时保护真实天体信号 |
| 色彩校准 | Color calibration | 根据选定参照调整颜色关系 |

暗场主要校准可重复的暗信号，不能消除单次曝光已经产生的随机噪声；平场也不能修复失焦。Bias或暗平场的使用需要与相机行为及校准流程匹配。[S7]

配准负责对齐，叠加负责合并。[S8] 拉伸显示已有的暗信号，不会增加原本没有记录到的信息；背景提取要保护真实星云、外围晕和尘埃。[S9、S10；信息说明为成像原理归纳]

## 易混概念速记

| 容易混淆 | 区别 |
| --- | --- |
| 光年与年 | 一个是距离，一个是时间 |
| 角秒与时间秒 | 一个描述角度，一个描述时间 |
| 视星等与绝对星等 | 一个描述从观测位置接收到的亮度，一个按规定距离比较 |
| 总星等与面亮度 | 一个是目标总体亮度，一个涉及单位角面积 |
| 光度与观测亮度 | 一个是发出的能量，一个与接收位置及传播有关 |
| 赤经赤纬与高度方位 | 前者描述天球位置，后者还依赖观测地点和时刻 |
| 视宁度与透明度 | 一个关乎大气造成的星像模糊，一个关乎透光情况 |
| 红化与红移 | 一个改变不同波长的相对强度，一个移动光谱特征的波长位置 |
| 导星与极轴校准 | 一个实时修正跟踪，一个调整架台轴向；两者不等价 |
| 配准与叠加 | 先确定对齐关系，再合并图像 |
| 增益与收光量 | 增益影响信号数字化，不会增加入射光子 |
| 行星状星云与行星 | 名称沿袭早期外观，物理来源不同 |
