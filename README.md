## 怎样添加笔记

主要维护方式是在聊天中提供文章链接或笔记，由助手整理并提交到本仓库：

**提供链接或笔记 → 整理并检查来源 → 更新阅读笔记及相关条目 → 提交到 GitHub → 返回链接和修改摘要。**

可以直接使用以下请求：

> 请把这篇资料整理进我的知识库：https://github.com/Max-lu-4416/knowledge-base 。资料链接或正文：……。请沿用现有模板，保留来源，更新相关百科条目和目录，上传后返回链接与修改摘要。

在其他聊天中继续维护时，请附上仓库链接。每次更新由消息触发；仓库没有自动抓取或定时发布任务。

也可以自己在 GitHub 编辑：打开文件后点击编辑按钮，修改并提交；新增内容时复制对应模板，填写后保存为 `.md` 文件。

## 写作与整理约定

- 阅读笔记以一篇文章或一本书为单位；主题百科以一个概念或问题为单位，持续补充不同来源。
- 使用中文 Markdown 和相对链接，保持 GitHub 页面内可直接阅读、跳转。
- 记录来源、原文发布日期和整理日期；未知的信息明确标注，不猜测。
- 分清来源观点、整理者归纳和本人补充。个人经历及个人立场只在本人明确提供后记录。
- 引用资料以概述为主，保留出处；新来源与原结论有分歧时保留差异和适用条件。
- 新增阅读笔记后更新阅读目录；新增或修改百科条目后同步主题目录及相关链接。
- 金融、法律、健康等话题注明知识边界，不把单一文章的观点写成普遍结论。
