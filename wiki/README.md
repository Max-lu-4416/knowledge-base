## 条目维护

1. 先查找已有条目，优先补充相关内容，再考虑新建。
2. 将可复用知识写入正文，逐篇阅读过程留在阅读笔记中。
3. 给具体观点标注来源；单一来源支撑的概括说明证据范围。
4. 遇到冲突时记录差异、背景和待验证问题。
5. 更新日期、来源、相关笔记，以及本目录和首页入口。
